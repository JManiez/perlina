# Perlina By L

Workspace du site de l’institut de beauté **Perlina By L** (La Grande-Motte).

## Site actuel

Le site en production est dans `perlina-next/` (Next.js 16).

```bash
cd perlina-next
npm install
npm run dev        # http://localhost:3000
```

Déploiement Vercel : [github.com/JManiez/perlina-by-l](https://github.com/JManiez/perlina-by-l)
