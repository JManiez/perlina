# Perlina By L

Workspace du site de l’institut de beauté **Perlina By L** (La Grande-Motte).

Le site en production est le projet Next.js, déjà sur GitHub :

**[github.com/JManiez/perlina-by-l](https://github.com/JManiez/perlina-by-l)**

## Contenu de ce dépôt

| Chemin | Rôle |
| --- | --- |
| `perlina-site/` | Première version HTML statique (Netlify) |
| `perlina-vercel/` | Ancienne version Next.js 14 |
| `perlina-by-l-maquette.html` | Maquette HTML initiale |
| `flyer.png` | Flyer |
| `contact_sheet.png` | Planche contact |

Le dossier local `perlina-next/` n’est **pas** inclus ici : c’est le dépôt `perlina-by-l` (Next.js 16), pour éviter de dupliquer le code.
